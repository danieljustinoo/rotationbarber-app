GUIA RAPIDO - ROTATION BARBER APP
=================================

Este ficheiro explica como voltar a abrir a app quando fechares tudo.

A pasta correta da app e:

/Users/next/Documents/Codex/2026-07-07/t/rotationbarber-app

Sempre que fores correr comandos, confirma que estas dentro dessa pasta.


1. MODO AO VIVO
===============

Usa este modo quando queres alterar textos, cores, componentes ou design no
Visual Studio Code e ver as mudancas aparecerem no simulador quase na hora.

Passo 1 - Abrir a pasta no Visual Studio Code
--------------------------------------------

Abre o Terminal e escreve:

cd /Users/next/Documents/Codex/2026-07-07/t/rotationbarber-app
code .


Passo 2 - Abrir o simulador
---------------------------

No mesmo terminal, ou noutro, escreve:

npm run sim:ios


Passo 3 - Ligar a API/base de dados
-----------------------------------

Abre um terminal dentro do Visual Studio Code e escreve:

npm run api

Deixa esse terminal aberto.


Passo 4 - Ligar o React em modo ao vivo
---------------------------------------

Abre outro terminal dentro do Visual Studio Code e escreve:

npm run dev

Deixa esse terminal aberto tambem.


Passo 5 - Abrir a app no simulador com live reload
--------------------------------------------------

Abre um terceiro terminal dentro do Visual Studio Code e escreve:

npm run run:ios:live

Depois disto, quando mudares algo no codigo e guardares o ficheiro, o simulador
deve atualizar sozinho.


Resumo do modo ao vivo
----------------------

Terminal 1:
npm run api

Terminal 2:
npm run dev

Terminal 3:
npm run run:ios:live


2. MODO NORMAL / CRIAR APP NO SIMULADOR
=======================================

Usa este modo quando queres criar uma versao normal da app para instalar no
simulador. Aqui as alteracoes nao aparecem automaticamente. Sempre que mudares
o codigo, tens de sincronizar e correr outra vez.

Passo 1 - Entrar na pasta certa
-------------------------------

cd /Users/next/Documents/Codex/2026-07-07/t/rotationbarber-app


Passo 2 - Ligar a API/base de dados
-----------------------------------

npm run api

Deixa esse terminal aberto.


Passo 3 - Sincronizar a app para iOS
------------------------------------

Noutro terminal:

npm run sync:ios


Passo 4 - Correr no simulador
-----------------------------

npm run run:ios


Resumo do modo normal
---------------------

Terminal 1:
npm run api

Terminal 2:
npm run sync:ios
npm run run:ios


3. SE DER ERRO DE PACKAGE.JSON
==============================

Se aparecer um erro a dizer que nao encontra o package.json, quase sempre quer
dizer que o terminal esta na pasta errada.

Volta a escrever:

cd /Users/next/Documents/Codex/2026-07-07/t/rotationbarber-app

E depois repete o comando.


4. NOTAS IMPORTANTES
====================

- O Visual Studio Code serve para editar a app.
- O Simulador da Apple serve para testar a app.
- O Xcode fica instalado por tras, mas normalmente nao precisas de o abrir.
- Para ver mudancas ao vivo, usa o MODO AO VIVO.
- Para criar/instalar a app como versao normal no simulador, usa o MODO NORMAL.
